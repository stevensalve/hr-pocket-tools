ID Card Maker

Employee ID cards on printable sheets, with photos if you have them.

Works offline - photos and details never leave this device

1. Employee list

Columns: Name and Employee ID are needed. Optional: Designation, Department, Blood Group, Emergency Contact, Valid Till.

2. Look

Name each file after the employee ID (E001.jpg) or the full name.

3. Create the sheets

Load a list to begin.

Print at 100% scale (not "fit to page") on card stock, then cut along the corner marks. For double-sided printing choose "flip on long edge". ID cards identify real people: store the source file and photos securely and delete them when no longer needed.
